## What is ClaPat Freebies?

ClaPat Freebies is a collection of free, standalone web components taken straight from ClaPat portfolio templates. Each component is plain HTML, CSS, and vanilla JavaScript — no React, no build process, no npm install. You drop the file into your project, open it, and it works. Every component is released under the MIT license, free for personal and commercial use.

These are the same building blocks used inside ClaPat's premium HTML templates and WordPress themes, released individually so you can try the code, learn from it, and use it anywhere.

## Why use these components?

- **Zero dependencies.** Pure vanilla JavaScript. Nothing to install, nothing to configure.
- **Copy-paste ready.** Each component is a self-contained folder with a live demo and a short README.
- **Real production code.** Extracted from ClaPat templates that ship to agencies and freelancers, not toy examples.
- **MIT licensed.** Use them in personal and client work, free.
- **Consistent motion language.** Built with GSAP and vanilla JS the same way across every component.

## Quick start

Each component lives in its own folder. To use one:

```bash
# 1. Download or clone the repo
git clone https://github.com/clapatstudio/clapat-freebies.git

# 2. Open the component folder you want
cd clapat-freebies/ascii-cursor-trail

# 3. Open index.html in your browser — that's it
```

Or just copy the component's `.js` and `.css` into your own project and follow its README.
